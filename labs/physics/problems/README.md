# 问题库使用说明

建议先从 [`SHORTLIST.md`](SHORTLIST.md) 选择课题，再打开对应的 `shortlist/TP-*/PROBLEM.md`。没有详细档案的题目也可以启动，但第一阶段必须补齐文献地图、精确定义、基线复现和停止条件。

评分使用 1–5 分：

- **C**（Codex fit）：是否适合以检索、推导、代码、求解器和审计为主要研究手段。
- **V**（Value）：若完成首个闭环目标，潜在学术价值。
- **资源 L/M/H**：首轮实验预计分别为 `<8 GiB`、`8–24 GiB`、`24–30 GiB`。H 级必须从小截断开始。

条目的“首个闭环目标”只定义第一篇可审计研究单元，不宣称足以解决整个母问题。
