# 原始文献与证据索引

检索日期：**2026-08-26**。优先记录原始论文和领域白皮书；目录中的“开放”判断是基于这些来源的明确 outlook、已实现边界或从最新结果得到的可检验延伸，不代表穷尽所有数据库。

<a id="s01"></a>
## S01 — 超对称矩阵量子力学

- [Lin, “Bootstrap bounds on supersymmetric matrix quantum mechanics” (arXiv:2510.01356)](https://arxiv.org/abs/2510.01356)：给出较大 bootstrap 系统和 `κ` 下界，并把特定 kink 解释为截断/求解器造成的伪结构；直接支持 TP-001。

<a id="s02"></a>
## S02 — BFSS 基态 bootstrap

- [Lin, “The BFSS model on the bootstrap” (arXiv:2410.14647)](https://arxiv.org/abs/2410.14647)：以较低 word length 获得 BFSS 基态关联函数的初始约束。
- [Kazakov et al., “High-precision bootstrap of multi-matrix quantum mechanics” (arXiv:2507.21007)](https://arxiv.org/abs/2507.21007)：把多矩阵 bootstrap 推到更高 word length 和高精度，为进一步 BFSS 计算提供方法基线。

<a id="s03"></a>
## S03 — 热矩阵量子力学

- [Lin, “Bootstrap bounds on thermal matrix quantum mechanics” (arXiv:2410.04262)](https://arxiv.org/abs/2410.04262)：指出当时的界尚不足以提取长弦激发和相互作用，并给出两矩阵初步结果。
- [“Thermal matrix bootstrap with conic optimization” (arXiv:2511.01209)](https://arxiv.org/abs/2511.01209)：后续改进了热能量和长弦信息，因此 TP-003 的目标被限定为继续分离激发态/相互作用，而不是重复旧问题。

<a id="s04"></a>
## S04 — 矩阵模型有限 N / 大 N

- [Kazakov et al. (arXiv:2507.21007)](https://arxiv.org/abs/2507.21007)：提供有限计算截断下的多矩阵高精度基线。有限 N 到大 N 的统一标度是从方法边界提出的 C 级延伸。

<a id="s05"></a>
## S05 — 有限 N lattice Yang–Mills bootstrap

- [Guo et al., “Bootstrapping lattice Yang–Mills theory at finite N” (arXiv:2404.16925)](https://arxiv.org/abs/2404.16925)：有限 N SU(2)、较长 loop 与 plaquette/free-energy 高精度界。
- [“Rigorous bootstrap bounds in SU(3) lattice Yang–Mills theory” (arXiv:2502.14421)](https://arxiv.org/abs/2502.14421)：在 2D–4D 给出 SU(3) plaquette Wilson loop 严格界，并展示 twist-reflection positivity 等增强。
- [Anderson & Kruczenski, “Loop equations and bootstrap methods in the lattice” (arXiv:2203.11360)](https://arxiv.org/abs/2203.11360)：大 N、D=2–4 的 loop-bootstrap 基础。

<a id="s06"></a>
## S06 — loop observables 与谱方向

- [Guo et al. (arXiv:2404.16925)](https://arxiv.org/abs/2404.16925)：已对 string-tension 相关量给出定性结果；直接严格约束 Creutz ratio/谱量仍是需重新审计的延伸。
- [SU(3) finite-N bootstrap (arXiv:2502.14421)](https://arxiv.org/abs/2502.14421)：提供反射正性和有限 N 实现基础。

<a id="s07"></a>
## S07 — 格点 Ising 严格关联函数界

- [Cho et al., “Bootstrapping the lattice Ising model” (arXiv:2206.12538)](https://arxiv.org/abs/2206.12538)：给出格点关联函数严格界，并报告三维初步结果。

<a id="s08"></a>
## S08 — conformal bootstrap 的方法缺口

- [Poland, Rychkov & Vichi, “The conformal bootstrap: Theory, numerical techniques, and applications”/Snowmass review (arXiv:2203.08117)](https://arxiv.org/abs/2203.08117)：明确讨论 functional 基、island 收敛、高精度成本、严格误差和 subleading data 等问题。
- [Alday et al., “Analytic conformal bootstrap and CFT data” (arXiv:2202.11012)](https://arxiv.org/abs/2202.11012)：讨论解析与数值 bootstrap 的缺口和进一步应用。

<a id="s09"></a>
## S09 — Hamiltonian truncation

- [Elias-Miró & Rychkov et al., “Hamiltonian truncation methods” (arXiv:2201.11696)](https://arxiv.org/abs/2201.11696)：outlook 明确列出散射/LSZ、CFT 三点函数 Fourier 变换、counterterms、非平衡与三维 O(2) 等技术缺口。

<a id="s10"></a>
## S10 — Hamiltonian / coarse-grained bootstrap

- [“Hamiltonian bootstrap” (arXiv:2410.00810)](https://arxiv.org/abs/2410.00810)：用 SDP 和对称约化处理量子多体 benchmark。
- [“Coarse-grained quantum bootstrap” (arXiv:2412.07837)](https://arxiv.org/abs/2412.07837)：在无限自旋链给出零温/有限温严格界，为更高维推广提供起点。

<a id="s11"></a>
## S11 — 热力学极限谱隙界

- [“Rigorous bounds on the spectral gap of quantum spin systems” (arXiv:2211.03819)](https://arxiv.org/abs/2211.03819)：建立从有限局域信息获得热力学极限 gap bounds 的方法基础。

<a id="s12"></a>
## S12 — 从谱重建隐对称

- [“Discovering hidden symmetries from spectral statistics” (arXiv:2604.01296)](https://arxiv.org/abs/2604.01296)：2026 年工作用扩展 spectral form factor 重建隐对称；TP-019 是对连续、投影或 non-invertible 情形的明确方法延伸。

<a id="s13"></a>
## S13 — 量子 Monte Carlo 符号问题

- [“The sign problem in quantum Monte Carlo simulation” (arXiv:2204.08777)](https://arxiv.org/abs/2204.08777)：综述基底依赖、复杂度和缓解策略，支持把问题收窄到参数化局域基变换族。

<a id="s14"></a>
## S14 — S-matrix bootstrap

- [“S-matrix bootstrap” Snowmass white paper (arXiv:2203.02421)](https://arxiv.org/abs/2203.02421)：明确讨论高点/一般运动学解析性、UV 信息、anyon、自旋、非弹性、四维 IR-safe observable、天球方向及无质量 dual bootstrap 等开放方向。

<a id="s15"></a>
## S15 — EFT positivity 与引力圈修正

- [“UV constraints on IR physics” (arXiv:2203.06805)](https://arxiv.org/abs/2203.06805)：EFT positivity/dispersion 关系的路线图。
- [“One-loop positivity bounds for scalar EFTs” (arXiv:2408.10318)](https://arxiv.org/abs/2408.10318)：展示圈级标量 positivity 的减除和解释细节。
- [“Gravitational positivity bounds at one loop” (arXiv:2501.17949)](https://arxiv.org/abs/2501.17949)：说明 graviton loops 下受控负性与 crossing-symmetric dispersion 的必要性。

<a id="s16"></a>
## S16 — 两圈六点 QCD 振幅

- [“The two-loop six-gluon amplitude in QCD at maximal weight” (arXiv:2510.20565)](https://arxiv.org/abs/2510.20565)：发现 137-letter 子字母表，并列出 NMHV、Landau 解释、非平面/多点、function-level 与低权重等 outlook。
- [“All two-loop six-gluon MHV amplitudes at maximal weight” (arXiv:2602.02783)](https://arxiv.org/abs/2602.02783)：显示 137-letter alphabet 在完整 MHV sector 中的进一步普适性；因此目录不再把“补齐 MHV”列为开放题。
- [“Two-loop six-gluon MHV amplitudes in QCD” (arXiv:2606.27801)](https://arxiv.org/abs/2606.27801)：2026 年汇总/完成结果，用于校正 TP-029–034 的当前边界。

<a id="s17"></a>
## S17 — 生成函数 IBP

- [“Symbolic reduction of Feynman integrals with generating functions” (arXiv:2605.09541)](https://arxiv.org/abs/2605.09541)：提出并在实例上测试生成函数化简算法；完整性证书、失败边界和新 family benchmark 是自然的近期延伸。

<a id="s18"></a>
## S18 — Feynman 积分的现代几何

- [SAGEX review, “Mathematical structures in Feynman integrals” (arXiv:2203.13014)](https://arxiv.org/abs/2203.13014)：系统梳理 multiple polylogarithms、elliptic/higher geometry、微分方程等方法。
- [“Machine learning symbol alphabets” (arXiv:2510.10099)](https://arxiv.org/abs/2510.10099)：2025 年探索字母表提取，可作为算法对照而非开放性唯一依据。

<a id="s19"></a>
## S19 — color–kinematics 与 double copy

- [“The SAGEX review on scattering amplitudes, Chapter 2: An invitation to color–kinematics duality and the double copy” (arXiv:2204.06547)](https://arxiv.org/abs/2204.06547)：总结圈级表示、含物质/高阶导数、背景与 kinematic algebra 的长期挑战。

<a id="s20"></a>
## S20 — 振幅与引力波

- [“Scattering amplitudes and the conservative Hamiltonian for binary systems”/Snowmass white paper (arXiv:2204.05194)](https://arxiv.org/abs/2204.05194)：概述 amplitude/EFT 通往经典引力波观测量的前沿。
- [“Post-Minkowskian theory meets the gravitational self-force” (arXiv:2203.13024)](https://arxiv.org/abs/2203.13024)：梳理 PM、自力与经典散射的连接。
- [“Gravitational waveforms at next-to-leading post-Minkowskian order” (arXiv:2402.06361)](https://arxiv.org/abs/2402.06361)：提供具体波形和 PN 匹配基线；TP-039 开题时必须先审计 2025–2026 后续阶数。

<a id="s21"></a>
## S21 — 宇宙学 cluster bootstrap

- [“Cluster bootstrap for cosmological correlators” (arXiv:2603.08670)](https://arxiv.org/abs/2603.08670)：对 de Sitter cubic scalar 的 chain/loop 图发现 A/B 型 cluster alphabets 与 adjacency，并在文中范围内展示低点唯一固定；直接生成 TP-042/043。

<a id="s22"></a>
## S22 — 宇宙学 bootstrap 与 de Sitter

- [“The cosmological bootstrap” Snowmass white paper (arXiv:2203.08121)](https://arxiv.org/abs/2203.08121)：总结奇点、幺正性、loops、AdS/dS 联系和非微扰 bootstrap 的开放方向。
- [“A nonperturbative bootstrap for de Sitter correlators” (arXiv:2107.13871)](https://arxiv.org/abs/2107.13871)：提供 dS2 示例和非微扰框架起点。

<a id="s23"></a>
## S23 — 超弦微扰振幅

- [“String perturbation theory” Snowmass white paper (arXiv:2203.09099)](https://arxiv.org/abs/2203.09099)：总结高 genus 振幅、modular graph functions 与低能展开的研究前沿。

<a id="s24"></a>
## S24 — 超共形场论

- [“Superconformal field theories in diverse dimensions” (arXiv:2202.07683)](https://arxiv.org/abs/2202.07683)：总结 3≤D≤6 SCFT 分类、几何、紧化和强耦合动力学问题。

<a id="s25"></a>
## S25 — tensor networks for lattice gauge theories

- [“Tensor networks for lattice gauge theories beyond one dimension” (arXiv:2407.03058)](https://arxiv.org/abs/2407.03058)：讨论超越一维、连续极限、非阿贝尔、有限密度和实时演化的主要困难。

## 开题时的补充检索要求

每题至少执行：题名关键词检索、方法关键词检索、引用/被引追踪、作者主页或后续论文追踪，以及最近两年 arXiv 分类检索。若发现结果已完成，应保留审计记录并把课题标为 `superseded`，不得静默改写成“我们最先解决”。
