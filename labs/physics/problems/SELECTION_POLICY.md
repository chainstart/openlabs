# 物理开放问题组合准入政策 v2

本目录只收录“母问题”，不把论文 outlook、算法 benchmark、某个积分族、某个 symbol
alphabet 或一次精度改进包装成开放问题。可计算性决定如何切工作包，不能替代问题的重要性。

## 硬性准入门

一个问题只有同时满足以下条件，才可进入活跃组合：

1. **共同体认可**：至少两项相互独立的权威证据，其中至少一项来自政府/学术机构战略报告、
   十年规划、正式大奖问题清单或跨机构共同体路线图。单篇论文的 discussion/outlook 不合格。
2. **仍然开放**：权威来源明确陈述核心未知，而不是由 OpenLabs 从“尚未计算某个例子”推断。
3. **领域级影响**：解决后会改变对基本规律、宇宙组成、物质结构或大型实验计划的理解；只改善
   一个代码、截断、字母表、图族或系数不够。
4. **持续关注**：存在跨团队、跨机构或长期实验/理论计划，而不是只有一个小组近期提及。
5. **三层分离**：目录陈述母问题；共同体认可的关键未知登记为 `recognized_subproblem`；具体
   可证伪任务登记为 `work_package`。工作包成功不自动等于子问题或母问题解决。
6. **当前性**：组合审计不超过 12 个月；工作包启动前再做近 24 个月专题查重。

## 自动淘汰条件

出现任一情形即不得作为独立开放问题：

- 唯一开放性依据是单篇论文的 outlook、脚注、补充材料或“future work”；
- 题目本质是多算一个点、提高一个截断、补一个 helicity/loop/graph family；
- 成功只证明工具更快、内存更低或 benchmark 更完整，却没有母问题层面的物理判别力；
- 需要以“可能有价值”“自然延伸”代替权威来源对重要性的明确说明；
- 主要卖点是容易由当前 Agent 完成，而不是科学共同体关心。

## 状态语义

- `active`：通过全部硬门，可接受新的工作包提案；
- `watch`：重要但开放状态或当前判别路线需复核，不得启动；
- `archived`：历史题目或技术工作包，仅保留 provenance；
- `superseded`：同一范围已由可靠先前工作解决。
