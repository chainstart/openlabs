# 单卡一天级材料发现研究计划

版本：2026-08-07
定位：从长周期 LLZTO 离子输运计算，转向可批量扩展的“隐藏有序结构 + 软模相变”发现平台

## 1. 结论先行

若目标是用一张 12 GB 显卡在一天内得到一个**值得继续验证的潜在论文结果**，最合适的单位不是“把一个材料的长分子动力学完整跑完”，而是：

1. 从公开实验平均结构中寻找部分占位、混占、空位或缺失轻元素；
2. 枚举一小批满足化学计量和对称性约束的隐藏有序结构；
3. 用两个独立通用势做短弛豫和一致性筛选；
4. 检查弛豫后是否出现新的低对称、极性、手性、铁弹性或输运网络；
5. 只把最强的约 0.5% 候选送入小规模 DFT 或实验验证。

主方向确定为：

- **主线 A：实验平均结构中的隐藏有序结构发现**；
- **主线 B：声子虚频和软模所指向的漏报低对称相**；
- **并行轻量线：实验数据矛盾、条件依赖和可复现性挖掘**；
- **方法学支撑：收敛判据和停止规则，但不靠简单换材料拆分论文**。

一天级筛选的产物不是可直接投稿的论文，而是一个具有明确新结构或新机制、能够在随后数天内用 DFT/文献/实验核验的候选。这个定义可防止把大量便宜但没有科学含量的筛选结果误当成论文成果。

## 2. 原 LLZTO 工作的状态与价值

原研究针对精确化学计量 Li6.5La3Zr1.5Ta0.5O12（LLZTO），研究实验衍射平均占位的不确定性如何传播到：

- Li 示踪扩散；
- 集体电荷扩散；
- 两者的 Haven 型关系；
- 占位、反向跳跃和协同扩散串等微观机制。

这不是对单一化学结构做一次普通模拟，而是一套“实验平均结构 → 多个占位实现 → 势函数适用域验证 → 长时输运 → 统计和实验对比”的完整证据链。

停止时已有的有效内容包括：

- 精确化学计量和电中性的有序结构生成；
- 可审计的模型、结构、协议和结果哈希；
- 700 K、占位实现 0 的 500.1 ps 轨迹已经分别通过示踪和集体输运的预注册收敛判据；
- 750 K 已经启动过，但完整温度、占位、速度、尺寸和体积矩阵尚未完成；
- 独立 DFT 势函数适用域门槛尚未完成，所以现有轨迹仍是条件性证据。

按后续指令，重计算队列和看门狗已经停止，研究代理进程暂停，GPU 在停止检查时为空闲。原始数据均保留，没有删除。

当前内容有方法学和工程价值，也有一个可信的 700 K 数据点，但还不足以支撑完整 Arrhenius 关系、占位总体效应或可投稿的机制结论。若坚持完成原设计，单卡仍可能需要数周；对“快速形成多个候选成果”的目标，投入产出比偏低。

计算进程本身是确定性程序，不持续消耗大模型 token。GPU/CPU 运行消耗的是机器时间和电力；只有 Codex 被唤醒进行规划、读日志、诊断或写报告时才消耗 token。

## 3. “方法论文”与“换材料系列论文”的边界

“离子输运模拟的收敛判据与停止规则”可以形成一篇方法或基准论文，前提是它解决了普遍存在的统计偏差，并在足够多种输运机制和材料类别上验证。它不是通过更换材料名称就能自然复制的论文模板。

同一方法换不同材料，只有出现以下至少一项时，才可能形成独立材料论文：

- 新结构或此前漏报的低对称相；
- 新输运维度、协同机制或载流子竞争；
- 新的结构—性质因果联系；
- 与实验矛盾且能解释矛盾来源；
- 可被实验检验的明确设计规则。

这与冷冻电镜发现新结构的逻辑相似：真正可发表的是“新结构改变了对材料的理解”，而不是“用同一仪器又观察了一个样品”。单纯替换材料并复用相同图表容易成为低增量切片式发表。

## 4. 2025–2026 年热点和拥挤程度判断

近期公开工作显示，以下宽泛赛道已经很拥挤：

- 通用机器学习原子势的泛化基准，例如 [UniFFBench](https://www.nature.com/articles/s43588-026-01019-4)；
- 高熵固态电解质的大规模组成筛选，已有 [113,098 个候选的工作](https://www.nature.com/articles/s41524-026-02116-8)；
- MOF 吸附和直接空气捕集，已有 [ODAC25 的约 7000 万次 DFT 计算和 1.5 万个 MOF](https://arxiv.org/abs/2508.03162)；
- 交替磁体数据库，已有可查询的 [Altermagnet Database](https://altermagnets.anyterial.se/)；
- 泛化聚合物性质预测，公开竞赛已有约 2600 名参与者，见 [Open Polymer Challenge](https://arxiv.org/abs/2512.08896)。

因此不建议把第一篇新工作定义成“再做一个通用势基准”“再筛一种掺杂配方”或“再训练一个性质预测器”。更有机会的是从已有数据库和平均结构中发现被表示方式掩盖的结构、机制或数据冲突。

| --- | --- | ---: | --- | --- | --- |
| 1 | 平均结构中的隐藏原子有序 | 6–20 h | 高 | 中 | A |
| 2 | 声子软模与漏报低对称相 | 8–24 h | 高 | 中 | A |

### 5.1 隐藏有序结构

许多实验 CIF 只给出部分占位、元素混占、统计空位或缺失 H。平均结构可能掩盖真实的局部有序、极性、离子通道、磁交换路径或相变序参量。

24 小时试点可以这样做：

1. 从 COD、MC3D 等公开来源选 30–50 个原子数较小、存在部分占位或混占的实验结构；
2. 对每个候选生成 16–64 个满足化学计量、最小距离和电荷约束的有序实现；
3. 用两个独立模型家族进行快速弛豫；
4. 比较能量排序的一致性、最终空间群、极性、配位、氢键和输运网络；
5. 只保留两个模型结论一致，且候选间能量差显著大于模型分歧的结果；
6. 对最强候选做小规模 DFT、原始论文复核和结构新颖性检索。

[XtalPaint](https://www.nature.com/articles/s41524-026-02090-1) 表明从不完整晶体结构恢复缺失轻元素已经成为可行方向；一项 [晶体结构错误分类工作](https://pubs.rsc.org/en/content/articlelanding/2025/ta/d5ta05426e) 也说明数据库结构质量本身包含可研究的问题。

可形成的系列主题包括：

- 平均结构表示不确定性图谱；
- 质子有序诱导的极性；
- 空位有序引起的离子网络连通性变化；
- 阳离子有序引起的磁交换或扩散维度变化；
- 阴离子有序与软模耦合；
- 占位有序—位移型相变耦合。

每个具体材料能否成为独立论文，取决于是否出现独立的新结构/新物理，并通过 DFT、衍射模拟、谱学或实验中的至少一种外部证据核验。

### 5.2 声子软模与低对称相

[Materials Project 声子数据 v1.1](https://zenodo.org/records/20196565) 覆盖 26,413 个条目；不必下载全部约 85 GB 原始数据，可先用索引筛选。通用势的声子预测已有专门的 [可靠性基准](https://www.nature.com/articles/s41524-025-01650-1)，所以论文新意应放在软模指向的新相和新性质，而不是“用 ML 势算声子”。

流程为：

1. 筛选小原胞、实验已报道、非磁且有显著虚频的结构；
2. 沿最不稳定本征模做正负多个振幅扰动；
3. 用两个势独立弛豫；
4. 判断是否形成双势阱、新子群、极性、手性、铁弹性或模竞争；
5. 复算候选相声子，确认虚频是否消失；
6. 对关键能量差和势垒做 DFT。

[Phonix](https://www.nature.com/articles/s41524-026-02033-w) 已经覆盖 6,641 种材料并报告一批反常热输运，因此后续更有价值的问题是结构基元、可调控性、方向切换和多晶型差异，而不是重复统计反常比例。

### 5.3 实验矛盾和条件依赖

[NEMAD](https://www.nature.com/articles/s41467-025-64458-z) 收录 67,573 条实验磁性记录；[材料因果机制数据集](https://www.nature.com/articles/s41597-026-06598-5) 从 61,766 篇论文中提取约 207,200 个机制关系。可以把同化学式、结构、制备条件和测量条件归一后，寻找跨论文分歧及其条件来源。

适合的系列问题包括：

- 相变温度的跨论文可复现性；
- 多晶型导致的铁磁/反铁磁切换；
- 制备过程到矫顽力的因果图；
- 无稀土磁体的性能—成本 Pareto 前沿；
- 同样的方法迁移到聚合物玻璃化温度、热导率和电池寿命。

这条路线算力最轻，但必须人工回到原始论文复核高排名结论。NEMAD 主要依赖 LLM 辅助校验，而因果数据集自己报告了非零幻觉率，不能把抽取记录直接当作实验事实。

### 5.4 公共轨迹中的输运新机制

[LiFlow](https://www.nature.com/articles/s42256-025-01125-4) 提供 4,186 个候选、四个温度的短轨迹。25 ps 适合异常筛选，不足以自动证明收敛扩散系数。

值得寻找的是：

- 一维到三维的通道转变；
- 协同跳跃和框架—移动离子耦合；
- 示踪快但集体输运低；
- 多载流子竞争；
- 温度或占位触发的通道重构。

收敛判据是这条线的质量控制层。只有发现新的材料机制时，才单独形成材料论文。

### 5.5 可回收聚合物

2026-07-31 发布的 [ROP 数据集](https://arxiv.org/abs/2608.00149) 含约 108.7 万个结构，并附单体、反应和合成可及性信息。可围绕“反应类别 × 可再生原料 × 可回收性 × 应用性质”设计系列，例如高玻璃化温度、低密度高热导、气体膜、介电材料和电池粘结剂/电解质。

这条线组合空间很大，但性质标签和可合成性不应只靠模型自证；没有实验合作者时，优先级低于结构发现。

## 6. 选定平台的统一架构

```text
公开实验平均结构
  ├─ 缺失 H / 部分占位
  ├─ 空位、阳离子、阴离子有序
  └─ 声子软模扰动
              ↓
     双模型快速弛豫与分歧估计
              ↓
 空间群 / 极性 / 手性 / 通道 / 声子 / 新颖性
              ↓
        前 0.5% 小规模 DFT
              ↓
 原始论文、模拟衍射/谱学或实验验证
```

平台可形成六类相互关联但不重复的论文：方法和数据质量图谱、质子有序、空位有序、阳离子有序、软模新相、以及有序—软模耦合。系列的共同部分是工具链，不是结论；每篇文章必须有独立的材料发现和外部验证。

## 7. 为什么先写工作流代码，而不是先写 Skill

推荐采用三层结构：

| 层 | 负责内容 | 是否确定性 |
| --- | --- | --- |
| Python 工作流 | 数据清单、结构解析、枚举、弛豫、分析、排序、哈希、恢复、预算和停止 | 是 |
| 版本化 JSON 协议 | 候选集、模型、阈值、资源上限、阶段开关和发表门槛 | 是 |
| Codex Skill | 何时调用哪个命令、怎样检查状态、何时要求人工复核、如何解释报告 | 主要是操作规范 |

科学计算逻辑不应写进 `SKILL.md`：提示词难以单元测试，也不适合负责随机种子、断点恢复、哈希、预算上限和结构约束。Skill 应当是薄的操作层，调用已经稳定的 CLI。

实施顺序为：

1. 先实现和测试 CPU 结构审计、协议验证、资源估算和不可变结果清单；
2. 用本仓库 LLZTO 平均结构与有序结构做校准，不声称新颖性；
3. 加入 30–50 个外部候选并进行人工候选门检查；
4. 再实现受预算控制的有序枚举和双模型弛豫；
5. CLI 在至少一个真实候选批次中稳定后，再创建自动发现的 Codex Skill；
6. Skill 只允许启动协议中已启用的阶段，不得自行放宽科学或资源门槛。

## 8. 首个 24 小时协议

首轮正式候选批次的硬限制建议为：

- 候选：30–50 个；
- 每个候选有序实现：初筛 16–32 个，只有高价值小结构升到 64 个；
- 独立势模型：至少两个不同模型家族；
- 总 GPU 预算：不超过 20 GPU·h；
- 总墙钟：不超过 24 h；
- 单候选预算达到 25% 时自动停止并报告；
- 任一模型发生结构崩坏或两模型排序严重不一致时，不进入 DFT；
- 只允许前 0.5%–2% 进入精验证。

首轮不是追求完整性质矩阵，而是回答三个二元问题：

1. 是否存在平均结构没有表达的稳定有序态？
2. 两个独立模型是否同意其结构类型和相对稳定性？
3. 新结构是否改变可发表的物理量或实验可观测量？

## 9. 发表门槛

一个候选只有同时满足以下条件，才标记为“潜在论文结果”：

- 新结构不是数据库重复项，也不是坐标容差造成的伪降对称；
- 结论不是单个势函数的偶然外推；
- 关键能量排序经过小规模 DFT 或等价独立证据确认；
- 新结构改变至少一项有意义的性质或机制；
- 给出实验可检验预测，如新增衍射峰、Raman/IR 模、极化、通道或相变信号；
- 原始实验论文和 CIF 的样品条件、占位不确定性及许可证已经核对；
- 负结果和模型分歧保留在筛选清单中，不事后修改阈值。

完成一个一天级批次，只代表形成候选。完成上述门槛后才适合撰写有分量的材料论文；若一批没有候选，也可以作为平台的校准和负结果，但不应强行包装成多篇材料论文。

## 10. 本仓库的实施入口

首个实施版本采用：

- `protocols/hidden_order_soft_mode_pilot_v1.json`：24 小时预算、阶段开关和校准候选；
- `matfactory-discover`：CPU 结构审计、候选路由、环境/预算检查和不可变报告；
- `runs/discovery/hidden-order-soft-mode-pilot-v1/`：运行时生成的审计 JSON 和 Markdown 报告；
- `tests/test_structure_discovery.py`：协议、占位审计、预算和不可变性测试。

第一版只执行零 GPU 的结构审计。枚举、双势弛豫、软模扰动和 DFT 阶段默认关闭，直到外部新颖性候选集通过人工检查。这样可以先验证研究问题和数据质量，再决定是否投入最多一天的单卡资源。

## 11. 2026-08-07 首次实施结果

校准协议已经实际执行，并生成不可变的 `audit.json` 和 `audit.md`。结果为：

- COD 1545083 平均结构被路由到“精确化学计量约束的隐藏有序”路线；
- 展开结构包含 136 个无序位点，其中 120 个为带空位的 Li 位点，16 个为 Zr/Ta 混占位点；
- 小数占位给出的平均原子数为 187.36，而精确晶胞应为 188；最大组成差为缺少 0.64 个 Li；
- 0.38/0.62 的 Li 占位和约 0.75/0.25 的 Zr/Ta 混占可用分母最小公倍数 8 的近似约束表示，但最终枚举仍必须直接强制 Li52La24Zr12Ta4O96，而不能只依赖小数舍入；
- 已有有序参考结构恰好为 188 个原子，组成检查通过；
- 若对一个候选生成 24 个实现并由两个模型各弛豫一次，粗略预算为 4.8 GPU·h，低于 20 GPU·h 上限；
- 实际授权和消耗的 GPU 时间仍为 0；CHGNet 已安装但模型制品尚未按新研究冻结，第二个独立 MACE 模型尚未安装，因此双模型门不通过；
- 当前价值是工作流和输入质量校准，没有新材料结论，也没有可撰写的论文成果。

随后对 COD 做了零 GPU 元数据摸底：2025 年、不含 C/H 的 Li 和 Na 两个查询合并后得到 100 条唯一记录。临时串行 CIF 下载因服务器响应慢被主动中止，没有把不完整结果纳入证据。正式候选采集必须先实现查询响应缓存、最多四路下载、礼貌限速、逐文件哈希和断点恢复，再生成 30–50 个候选的版本化清单。
