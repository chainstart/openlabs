# Mechanism archetypes

Use these as prompts for representation search, not as a checklist of cosmetic vocabulary.

| Archetype | Diagnostic question |
|---|---|
| Matching primal and dual certificates | Can a universal obstruction and an attaining construction meet at one threshold? |
| Moving certificate space | Is the classical proof fixing a projection, basis, shell, or test space that should vary? |
| Common structural host | What object can simultaneously contain the two structures needed for a contradiction? |
| Invisible deformation | What information does the target functor or invariant forget, and what second invariant detects it? |
| Target-specific complexity measure | What measure is large for the target but provably small for a nearby easy comparator? |
| Rare-event-stable conditioning | Which estimate explodes under conditioning, and can it preserve the original weight? |
| Algebraic reconstruction | Can local low-complexity data force one global polynomial, root set, or representation? |
| Geometric or analytic lift | Does a discrete problem become convex, spectral, toric, probabilistic, or harmonic with computable endpoints? |
| Self-enhancing recursion | Can each recursive stage improve the invariant instead of tensoring a fixed gadget? |
| Quantifier diagonalization | Can different members of a universal family require different witnesses or parameter fields? |
| Bounded potential ascent | Would every forbidden embedding or hard branch force a bounded potential to increase? |

For each promising archetype, state:

- the new information retained;
- the inherited loss it repairs;
- the decisive lemma;
- the easiest adversarial model;
- the nearest easy comparator on which the idea should fail;
- the exact public conclusion it would change.
