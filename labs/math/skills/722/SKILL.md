# 722数学发现

中文名称：**722数学发现**；简称：**722技能**；调用名：`$722`。

Pursue the user's exact mathematical target, allowing substantial exploration before a provable
bridge exists. This experimental workflow learns from public OpenAI research summaries; it does
not reproduce their unpublished model or claim an equivalent compute budget.

For a managed run read the project, bound policy, task envelope and workstream. Use the registered
`math-discovery` protocol and its `math-discovery-v1` allocation profile. For a direct invocation,
create an isolated project using [runtime.md](references/runtime.md); creating it does not start
workers. Preserve existing projects and the user's model, budget and task scope.

Freeze a precise statement with its hypotheses, quantifiers, boundaries, best known result and
what that result fails to establish. Distinguish the source problem from a chosen specialization.
Accept proof or disproof when the user permits both; do not presume an affirmative solution exists.

Explore substantially different representations. For each route identify the information it retains,
the inherited loss it could remove, the decisive lemma and a cheap test capable of falsifying it.
Choose computations to distinguish mechanisms, not merely accumulate favorable instances.
Keep useful failed routes: a counterexample to an intermediate lemma is not a counterexample to
the source problem. Do not reopen an unchanged obstruction because a new round is available.

At checkpoints write a ledger entry with concrete new facts or negative evidence, exact remaining
gap, parameter/limit losses and next discriminating action. Keep the same statement and preserve
old entries. A budget deadline ends an allocation, not the mathematical investigation: checkpoint
before returning, and resume from evidence when the controller allocates another attempt.
Allocation depends on actual progress, not optimism, agent counts or document counts.

A candidate must include a precise statement, ordinary mathematical proof and explicit dependency
interface. Move it to the policy's fresh reviewer boundary; the reviewer reconstructs the crucial
steps without inheriting the creator's favored reasoning. Check conditional laws, global
compatibility, nonvanishing, parameter costs and order of limits. An audited intermediate theorem
remains an intermediate theorem. The terminal `reconstructed_result` means a candidate survived
mathematical reconstruction; it does not certify source-problem closure, novelty or publication.

Use [mechanisms.md](references/mechanisms.md) for targeted exploration and audit prompts. Use
[runtime.md](references/runtime.md) for commands, ledger schema, budgets and usage accounting.
Run interpreters and computations through the repository resource guard. Record the effective
model/effort and measured usage separately from wall time; missing usage stays unknown. `max`,
`ultra` and API `pro` are not interchangeable, and none implies “Pro-equivalent hours”.

Delegation is optional when authorized and available. Preserve early independence between routes,
share only after their mechanisms and gaps are concrete, and charge all agents to the same budget.
Do not automatically activate paper workflows, Lean, external submission or research timers.
