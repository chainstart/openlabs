# OpenLabs quantitative-finance paper

Follow the shared workflow in `../openlabs-paper-writing/SKILL.md`
(`workflows/paper/skills/openlabs-paper-writing/SKILL.md` in the code repository). Identifiers
and public file names: [paper-identifiers.md](../references/paper-identifiers.md). Venue,
review and author policy: `registry/settings.yaml`. This file adds only what differs for quantitative finance.

## Quant specifics

- Components: `scientific-writing`, `statistical-analysis`; `peer-review` only as an assigned
  reviewer.
- Recover the complete registered search family, including failed and null trials. A selected
  pilot, a reused holdout or a nominal p-value after adaptive search is not confirmation.
- Use point-in-time data: vintages, revisions, delistings, corporate actions, calendars; current
  constituents or revised macro data cannot stand in for historical information.
- Report gross and net results with costs, lag, turnover, capacity, borrow, leverage, drawdown,
  exposures, uncertainty and multiplicity; compare simple baselines and the closest published
  methods under matched information and risk.
- A backtest is conditional historical evidence, not a forecast or investment advice; no
  real-money trading.
