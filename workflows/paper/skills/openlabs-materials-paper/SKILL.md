# OpenLabs materials paper

Follow the shared workflow in `../openlabs-paper-writing/SKILL.md`
(`workflows/paper/skills/openlabs-paper-writing/SKILL.md` in the code repository). Identifiers
and public file names: [paper-identifiers.md](../references/paper-identifiers.md). Venue,
review and author policy: `registry/settings.yaml`. This file adds only what differs for computational materials science.

## Materials specifics

- Components: `scientific-writing`; `statistical-analysis` for inference, uncertainty or
  hierarchical sampling; `peer-review` only as an assigned reviewer.
- Map every composition, phase, structure, preparation, temperature/pressure, observable and
  mechanism to a hash-bound artifact.
- Separate pilot, converged production, sensitivity, independent first-principles reference and
  experimental evidence. A universal or learned potential is not its own validator.
- Frames from one preparation are correlated; report the true independent unit.
- Check convergence and finite-size/time/ensemble sensitivity, model and pseudopotential
  provenance before strengthening a claim. Keep non-convergence and disagreement with reference
  calculations. Say "causal mechanism" only when the design identifies it; agreement with
  experiment alone may be error cancellation.
